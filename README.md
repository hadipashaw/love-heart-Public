# ❤️ Love Heart

A small, romantic browser animation that forms a heart from **“I love you” in 20 languages**.

The heart is drawn on an HTML canvas against a black background. After its initial formation animation, it continues with a soft breathing glow.

## ✨ Features

- Heart shape built from multilingual love phrases
- Animated outline and fill sequence
- Gentle breathing / brightness animation
- Responsive canvas that adapts to the viewport
- Seeded layout for a consistent arrangement
- Runs directly in a modern browser—no build tools or dependencies required

## 🚀 Run

Open `index.html` in a modern browser.

Or publish the repository with **GitHub Pages**:
1. Open the repository’s **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.

Once deployment finishes, GitHub Pages will provide the live site URL.

## 🛠️ Built with

- HTML
- CSS
- JavaScript
- HTML Canvas

Google Fonts are used for typography; an internet connection may be needed to load them.
